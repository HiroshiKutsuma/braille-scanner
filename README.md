# 点字スキャナー（試作版）

スマホのカメラで撮った点字の写真から、点字を読み取って仮名・英字に変換するWebアプリです。

**使ってみる：** https://hiroshikutsuma.github.io/braille-scanner/

## 使い方

1. 上のリンクをスマホのブラウザ（Chrome など）で開きます。
2. 「写真を撮る」で点字を撮影するか、「ギャラリーから選ぶ」で写真を選びます。
3. 写真の上に、見つけた点（オレンジの丸）とマス（青い枠）が表示され、下に読み取り結果が出ます。

うまく撮るコツ：

- 点字の部分に近づき、紙とスマホをなるべく平行にして撮ると正確になります。
- 斜めから光が当たって、点に影ができていると読み取りやすくなります。
- 紙全体を撮っても読めますが、点が小さくなるぶん間違いが増えます。

## できること

- 点の大きさと感度を自動で判断します（うまくいかないときは「手動」に切り替えられます）。
- 写真の傾きや、斜めから撮ったゆがみを補正します。
- 紙全体を撮ったときは紙の範囲を見つけ、机などの模様を点と間違えないようにします。
- 清音・濁音・半濁音・拗音・数符・外字符・外国語引用符に対応しています。
- 書く面（凹面）から撮った写真も読めます。

## ご注意

- **試作版です。** 読み取りはまだ間違えることがあります。点訳の最終確認には使わないでください。
- 読めないマスは ◇ で表示します。写真の端や紙のふちで切れているマスも ◇ になります。
- 写真はスマホの中だけで処理し、どこにも送信しません。

## 読み間違いを見つけたら

撮った写真と正しい読みを教えてもらえると、改良にとても役立ちます。
